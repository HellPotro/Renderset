# Tipografías incluidas

Todas se distribuyen con la SIL Open Font License 1.1 (https://openfontlicense.org),
que permite usarlas, incrustarlas en documentos y redistribuirlas con la aplicación.
Ficheros tomados de los paquetes @fontsource (v5.3.0), subconjunto latín, pesos 400 y 700.

| Familia | Ficheros |
|---|---|
| Inter | inter-latin-*.woff2 |
| Roboto | roboto-latin-*.woff2 |
| Open Sans | open-sans-latin-*.woff2 |
| Lato | lato-latin-*.woff2 |
| Montserrat | montserrat-latin-*.woff2 |
| Source Sans 3 | source-sans-3-latin-*.woff2 |
| IBM Plex Sans | ibm-plex-sans-latin-*.woff2 |
| Nunito Sans | nunito-sans-latin-*.woff2 |
| Poppins | poppins-latin-*.woff2 |
| Barlow | barlow-latin-*.woff2 |
| Merriweather | merriweather-latin-*.woff2 |
| Roboto Mono | roboto-mono-latin-*.woff2 |

Para añadir otra: copiar sus `-latin-400-normal.woff2` y `-latin-700-normal.woff2` aquí,
añadirla a `ReportThemeFonts.WebFonts` (Renderset.Core) y su `@font-face` a `css/report-fonts.css`.
